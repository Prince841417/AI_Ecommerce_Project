## 📌 Overview

This application simulates a real-world online shopping platform with:

- Secure user authentication  
- Dynamic product listing  
- Cart management system  
- AI-based product recommendation  
- Razorpay payment integration  
- Order tracking  
- Automated PDF invoice generation  

---

## 🛠️ Tech Stack

**Backend:** Flask (Python)  
**Frontend:** HTML5, CSS3  
**Database:** SQLite  
**Payment Gateway:** Razorpay  
**PDF Engine:** ReportLab  
**Deployment:** Railway  

---

## 🏗️ Architecture

Client → Flask Server → SQLite Database  
             ↘ Razorpay API  
             ↘ Invoice Engine
